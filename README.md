# Chaitra B V — Portfolio

Personal portfolio of Chaitra B V, a software engineer based in Frankfurt, Germany, building AI-powered developer tools, LLM integrations, and backend systems.

**Live site:** https://chaitrabv-dev.github.io

## What's inside

- Hero, about, skills, projects, experience, education, and contact sections
- Five color themes (Indigo, Midnight, Forest, Sunset, Aurora) with a switcher in the top bar. The choice is remembered, and the first visit follows the visitor's light or dark system setting
- Scroll animations, count-up numbers, and hover effects, all switched off for visitors who prefer reduced motion
- SEO basics: page title and description, Open Graph and Twitter tags, and JSON-LD structured data
- Downloadable resume

## Built with

Plain HTML, CSS, and a little JavaScript. No framework, no build step. Fonts come from Google Fonts (Bricolage Grotesque, IBM Plex Sans, JetBrains Mono).

## Files

| File | Purpose |
|---|---|
| `index.html` | Page content and SEO metadata |
| `style.css` | Layout, the five themes, and animations |
| `script.js` | Theme switcher, scroll progress, scroll reveal, count-up, card spotlight |
| `Chaitra_BV.pdf` | Resume linked from the page |

## Run it locally

Open `index.html` in a browser. Nothing needs to be installed.

## Update the content

- **Text, projects, experience:** edit `index.html`.
- **Resume:** replace `Chaitra_BV.pdf` and keep the same file name.
- **Colors:** each theme is a block of CSS variables at the top of `style.css`.
- **Add a theme:** add a `:root[data-theme="name"]` block in `style.css`, a swatch button in `index.html`, and the theme name to the `THEMES` list in `script.js` and to the small script in the `<head>` of `index.html`.

## Deployment

Hosted on GitHub Pages from the `main` branch. Push changes to `main` and the site updates in a minute or two.
